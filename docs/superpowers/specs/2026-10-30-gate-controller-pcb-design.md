# ParkQ Gate Controller PCB – Design

วันที่ 30 ต.ค. 2569 · สำหรับวิชาไฟฟ้า/IoT (อาจารย์ตรวจใน EasyEDA Std)

## 1. เจตนาและเหตุผล

บอร์ดนี้คือ "ตู้หน้าลาน" ของโมเดลลานจอด ParkQ ทำหน้าที่ 3 อย่างผ่าน Device API ที่มีอยู่แล้ว (README หัวข้อ "บอร์ด ESP32"):

1. อ่าน QR จากเครื่องอ่าน แล้วส่งไปที่ `POST /api/gate/{lot}/in|out/scan`
2. อ่านเซ็นเซอร์รายช่อง แล้วส่งไปที่ `POST /api/iot/{lot}/slots`
3. ดึง `GET /api/iot/{lot}/commands` แล้วสั่งไม้กั้นเปิด

ผู้ใช้ต้องการบอร์ดที่ **สั่งผลิตได้ หาชิ้นส่วนซื้อง่าย และใช้งานได้จริง** สำหรับโมเดลสาธิต

## 2. เป้าหมาย / ไม่ใช่เป้าหมาย / ล้มเหลวถ้า

- **เป้าหมาย:** PCB 2 ชั้น สั่ง JLCPCB จาก EasyEDA Std ได้ บัดกรีเองด้วยหัวแร้งธรรมดา เสียบอุปกรณ์แล้วระบบเดโมทำงานครบ (สแกน → ไม้กั้นเปิด, เซ็นเซอร์ → สถานะบนเว็บ)
- **ไม่ใช่เป้าหมาย:** คุมไม้กั้นจริง 12/24V, รีเลย์, วางชิป ESP32 เอง, ประกอบชิ้นส่วนโดยโรงงาน (SMT assembly), กล่องใส่บอร์ด
- **ล้มเหลวถ้า:** ESP32 รีเซ็ตเองตอนเซอร์โวขยับ, ขาเครื่องอ่าน QR ส่งไฟ 5V เข้า ESP32 จนเสีย, ต้องแก้ลายบอร์ดเพื่อเปลี่ยนอุปกรณ์, นำเข้า EasyEDA แล้วอาจารย์เปิดดูไม่ได้

## 3. ข้อจำกัด

- อาจารย์ตรวจไฟล์ใน **EasyEDA Std** → ไฟล์สุดท้ายต้องอยู่ใน EasyEDA Std
- ชิ้นส่วนแบบขาเสียบ (Through-hole) ทั้งหมด หาได้ใน LCSC และร้านไทย
- ขนาดไม่เกิน 100×100 มม. (ราคาขั้นต่ำของ JLCPCB)
- กำหนดเสร็จตามแผน W2: 23 พ.ย. 2569

## 4. วิธีที่พิจารณา (Approaches)

| วิธี | ข้อดี | ข้อเสีย |
|---|---|---|
| **1. สร้างไฟล์ KiCad แล้วนำเข้า EasyEDA Std** (เลือก) | เร็ว แบบตรวจแล้ว | ชิ้นส่วนไม่ผูก LCSC, อาจต้องจัดหน้าตาหลังนำเข้า |
| 2. เขียนไฟล์ EasyEDA Std โดยตรง | ไม่ต้องแปลง | รูปแบบไม่มีเอกสาร เสี่ยงเปิดไม่ขึ้น |
| 3. ผู้ใช้วาดเองตามคู่มือ | เข้าใจทุกเส้น, ผูก LCSC | ใช้เวลาผู้ใช้หลายชั่วโมง |

ผู้ใช้เลือก **วิธี 1** — ชดเชยความเข้าใจด้วยเอกสารอธิบายวงจรไว้ตอบอาจารย์ ถ้านำเข้าแล้วส่วนไหนเสีย ถอยไปวิธี 3 เฉพาะส่วนนั้น

## 5. สิ่งที่ผู้ใช้ตัดสินแล้ว

- ไม้กั้นโมเดล 2 ตัว (เข้า/ออก) ใช้ **เซอร์โว SG90**
- **4 ช่องจอด** ใช้โมดูลเซ็นเซอร์ IR
- เสียบ **ESP32 DevKit** แทนการวางชิปเอง

## 6. แบบที่ผมเสนอ (การตัดสินใจของผม — แก้ได้)

### 6.1 ชิ้นส่วนหลัก

| ส่วน | ชิ้นส่วน | เหตุผล |
|---|---|---|
| สมองหลัก | ESP32 DevKit V1 30 ขา (DOIT) เสียบบน Female header 1×15 สองแถว ห่าง 25.4 มม. | ขายทั่วไป ถอดเปลี่ยนได้ |
| ไฟเข้า | แจ็ค DC 5.5×2.1 มม. รับ Adapter 5V 2A + ไดโอด Schottky SS34 กันต่อกลับขั้ว + ฟิวส์รีเซ็ตได้ 2A | เซอร์โวกระชากกระแส ห้ามพึ่งไฟ USB |
| เลี้ยง ESP32 | ไฟ 5V หลังไดโอด เข้าขา VIN ของ DevKit (เรกูเลเตอร์บน DevKit แปลงเป็น 3.3V เอง) — ห้ามเสียบ USB กับ Adapter พร้อมกันตอนต่อเซอร์โว | การตัดสินใจของผม |
| เก็บประจุ | ตัวเก็บประจุ 470µF/16V + 100nF ใกล้ขั้วเซอร์โว | กันไฟตกจน ESP32 รีเซ็ต |
| ไม้กั้น | ขั้วต่อ 3 ขา 2.54 มม. × 2 (GND, 5V, SIG) | เสียบสาย SG90 ได้ตรง |
| เครื่องอ่าน QR | ขั้วต่อ 4 ขา 2.54 มม. × 2 (5V, GND, TX, RX) รองรับ GM65 / GM861 แบบ UART | |
| เซ็นเซอร์ | ขั้วต่อ 3 ขา × 4 (3V3, GND, OUT) | เลี้ยงด้วย 3.3V เพื่อให้สัญญาณออกไม่เกิน 3.3V |
| แสดงผล | LED เขียว/แดง + ตัวต้านทาน 330Ω, บัซเซอร์แบบ Active 5V ขับผ่านทรานซิสเตอร์ S8050 + ไดโอด 1N4148 | บอกผลสแกนผ่าน/ไม่ผ่าน |
| อื่นๆ | LED ไฟเข้า, รูยึด M3 × 4 มุม | |

### 6.2 การใช้ขา ESP32

| ขา | ใช้กับ | หมายเหตุ |
|---|---|---|
| GPIO16 / 17 | QR ขาเข้า RX / TX (UART2) | |
| GPIO32 / 33 | QR ขาออก RX / TX (UART1 ย้ายขา) | |
| GPIO18 | เซอร์โวขาเข้า | สัญญาณ PWM |
| GPIO19 | เซอร์โวขาออก | |
| GPIO34, 35, 36, 39 | เซ็นเซอร์ช่อง 1–4 | ขาอินพุตอย่างเดียว เหมาะกับเซ็นเซอร์ |
| GPIO23 / 22 | LED เขียว / แดง | |
| GPIO4 | บัซเซอร์ | |
| เลี่ยง | GPIO0, 2, 5, 12, 15 | เป็นขาที่มีผลตอนบูต |

### 6.3 ความปลอดภัยของสัญญาณ QR

ระดับสัญญาณของ GM65/GM861 ต้องยืนยันจาก datasheet ของรุ่นที่ซื้อจริง ผมจะใส่ตัวต้านทาน 1kΩ อนุกรมที่ขา RX ของ ESP32 ทุกเส้น และเว้นที่วางตัวต้านทานแบ่งแรงดัน (2kΩ/3.3kΩ) ไว้ **ใส่เฉพาะเมื่อเครื่องอ่านส่งสัญญาณ 5V** ถ้าเป็น 3.3V ให้ข้ามจุดนี้

### 6.4 บอร์ด

- 2 ชั้น ขนาดประมาณ 80×70 มม. ลายสัญญาณ 0.3 มม. ลายไฟ 5V/GND อย่างน้อย 1.0 มม. เทกราวด์ทั้งสองด้าน
- ติดชื่อขั้วต่อบนบอร์ด (Silkscreen) ทุกจุด เช่น `SERVO-IN`, `QR-OUT`, `SLOT1`
- ชื่อบอร์ด "ParkQ Gate Controller v1 · กลุ่ม ParkQ"

## 7. สิ่งที่ส่งมอบ

1. ไฟล์วงจรและลายบอร์ดรูปแบบ KiCad ที่นำเข้า EasyEDA Std ได้
2. คู่มือนำเข้า EasyEDA Std ทีละขั้น และวิธีสั่ง JLCPCB
3. รายการชิ้นส่วน (BOM) พร้อมรหัส LCSC และราคาโดยประมาณ
4. เอกสารอธิบายวงจรทีละส่วน (ไว้ตอบอาจารย์)
5. โค้ด ESP32 ตัวอย่างที่ใช้ขาตามตาราง 6.2 — **ถามผู้ใช้ก่อนว่าต้องการในรอบนี้ไหม**

## 8. ความเสี่ยงและสิ่งที่ปล่อยให้ผู้สร้างตัดสิน

- **EasyEDA Std รองรับการนำเข้า KiCad เวอร์ชันไหน** — ต้องทดสอบก่อนเป็นขั้นแรก ด้วยไฟล์ทดลองเล็กๆ (ไม่กี่ชิ้น) ถ้ารับแค่รูปแบบ KiCad 5 ให้สร้างรูปแบบนั้น
- **การเดินลาย:** ผู้สร้างเลือกได้ว่าจะเดินลายในไฟล์เอง หรือวางชิ้นส่วนแล้วใช้ Auto Router ของ EasyEDA (ต้องตรวจ DRC ผ่านทั้งสองกรณี)
- ระยะห่างแถวขาของ DevKit ที่ซื้อจริง (25.4 หรือ 22.86 มม.) — วัดก่อนสั่งบอร์ด
